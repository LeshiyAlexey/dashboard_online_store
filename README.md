##  Задача проекта

Создать удобный инструмент для анализа ключевых метрик интернет-магазина:
- **Выручка** — сколько зарабатывает магазин
- **Заказы** — динамика и распределение по дням недели
- **Клиенты** — уникальные пользователи и их сегменты
- **Товары** — лидеры продаж и категории, приносящие наибольшую прибыль
Дашборд позволяет в реальном времени фильтровать данные и визуализировать результаты для быстрого принятия бизнес-решений.

## Возможности дашборда

### Фильтры
- **Диапазон дат** — выбор любого периода заказов
- **Сегменты клиентов** — множественный выбор (можно комбинировать)
- **Категории товаров** — множественный выбор

### Ключевые метрики
- Общее количество заказов
- Общая выручка
- Количество уникальных пользователей
- Средний чек

### Визуализации (интерактивные Plotly-графики)
- **Топ-10 товаров по выручке** — горизонтальная столбчатая диаграмма
- **Выручка по категориям** — круговая диаграмма
- **Заказы по дням недели** — линейный график с маркерами

### Аналитические выводы
Сформулированные выводы на основе данных:
- Основная выручка приходится на категорию «Электроника»
- Пик заказов наблюдается в пятницу
- Лидер продаж — «Ноутбук ASUS VivoBook»

## Используемые технологии
Python, Streamlit, Pandas, Plotly, NumPy, Pathlib

## Структура проекта

| Файл/Папка | Описание |
|------------|----------|
| `data/` | Исходные данные (CSV-файлы) |
| `data/items.csv` | Товары: item_id, name, category, price_per_unit, base_price |
| `data/orders.csv` | Заказы: order_id, user_id, item_id, quantity, order_date |
| `data/users.csv` | Клиенты: user_id, name, user_segment, registration_date |
| `src/` | Пакет с модулями |
| `src/__init__.py` | Инициализация пакета (пустой файл) |
| `src/data_loader.py` | Загрузка CSV-файлов с кэшированием (@st.cache_data) |
| `src/data_merge.py` | Объединение трёх таблиц в один DataFrame |
| `src/data_cleaner.py` | Очистка данных (пропуски, проверка/исправление типов) |
| `app.py` | Главный файл дашборда Streamlit |
| `requirements.txt` | Список зависимостей |
| `.gitignore` | Исключения для Git (venv, __pycache__, .vscode и др.) |
| `README.md` | Документация проекта (этот файл) |

### Описание модулей

**`src/data_loader.py`**
- Загружает CSV-файлы из папки `data/`
- Использует `@st.cache_data` для кэширования
- Выводит информативные сообщения о загруженных данных

**`src/data_merge.py`**
- Объединяет три таблицы по ключевым полям

**`src/data_cleaner.py`**
- `handle_missing_values()` — удаляет строки с пропусками
- `check_and_fix_data_types()` — проверяет и исправляет типы данных

## Установка и запуск

### Предварительные требования
- Python 3.8 или выше
- Git (для клонирования репозитория)

### Шаг 1: Клонируйте репозиторий
### Шаг 2: Создайте виртуальное окружение
### Шаг 3: Установите зависимости
    pip install -r requirements.txt
### Шаг 4: Запустите дашборд
    streamlit run app.py
